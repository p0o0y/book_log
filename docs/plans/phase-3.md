# Phase 3 — 책 관리: 상태 변경 · 진행률 업데이트 · 완독 처리 · 수정 · 삭제

> 시작 전 [README.md](README.md)의 공통 컨텍스트를 읽을 것. **선행 조건: Phase 1 완료** (Phase 2와는 독립적이나 순서상 이후 권장).

## 오버뷰

책을 등록한 뒤 상태를 바꿀 방법이 전혀 없다. 찜한 책을 "읽는 중"으로 옮기거나, 읽는 중인 책의 현재 페이지를 갱신하거나, 완독 처리하거나, 잘못 등록한 책을 수정/삭제하는 것이 모두 불가능하다. 이번 단계에서 책 생애주기(찜 → 읽는 중 → 완독)를 관리하는 기능을 책 상세 페이지에 추가한다.

`Book` 타입 참고: `status`(reading/finished/wishlist), `startDate?`, `finishDate?`, `currentPage?`, `totalPages?`. 상세 페이지는 `status === "reading"`이고 `currentPage`/`totalPages`가 있을 때만 진행률 바를 보여준다.

**구현 방침**
- 저장소의 `updateBook(id, patch)` / `deleteBook(id)` 활용 (없으면 구현).
- 서버 액션은 `web/src/app/(main)/books/[id]/actions.ts`에 모은다.
- 상태 전이 시 날짜 자동 처리: wishlist → reading이면 `startDate`를 오늘로, → finished면 `finishDate`를 오늘로 기록(사용자가 폼에서 수정 가능하면 더 좋음). finished → reading 재독 전환 시 `finishDate` 제거.
- 진행률 업데이트: 읽는 중인 책 상세에 현재 페이지 입력 → 저장 UI 추가. `currentPage`가 `totalPages` 이상이면 완독 전환을 제안하거나 자동 처리.
- 책 정보 수정: `/books/[id]/edit` 라우트 신설 — 제목/저자/출판사/총 페이지/상태/날짜 수정 폼 (책 등록 폼과 공용 컴포넌트로 추출 가능하면 추출).
- 책 삭제: 확인 후 삭제하고, 해당 책의 독후감·유튜브 영상 데이터도 함께 정리한 뒤 서재(`/`)로 redirect.
