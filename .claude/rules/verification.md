# 검증 원칙

- 모호하거나 확실하지 않은 내용은 추측으로 단정하지 말고, 확인이 어려우면 "확인 필요"라고 명시하거나 사용자에게 질문한다.
- 코드를 수정했으면 관련 검증을 실제로 실행하고 결과를 보고한다: `cd web && npx eslint <대상>`, `cd web && npx tsc --noEmit`. 필요하면 `npm run test`, `npm run test:e2e`도 함께 확인한다.
- 실행하지 않고 "될 것 같다"는 추정으로 검증을 끝냈다고 보고하지 않는다.
