# 에이전트 오케스트레이션

- 기능 구현이나 버그 수정처럼 코드를 실제로 변경하는 작업을 끝냈으면, 커밋/PR 전에 `code-reviewer` 에이전트를 호출해 품질·보안 검토를 받는다. 리뷰는 메인 대화 컨텍스트를 오염시키지 않도록 별도 에이전트로 위임하고, 결과만 요약해서 반영한다.
- 코드베이스 조사 범위가 넓어 여러 영역을 동시에 훑어야 하면 Explore 서브에이전트를 병렬로 띄운다(최대 3개, 영역별로 분담). 순차 탐색보다 이쪽이 빠르고 메인 컨텍스트도 덜 어지럽힌다.
- 중간에 사용자 피드백을 받으며 방향을 조율해야 하는 작업(기능 구현, 기획)은 Skill(메인 대화)로 진행하고, 결과만 받으면 되는 독립 작업(리뷰, 탐색, 검증)은 Agent로 위임한다.
